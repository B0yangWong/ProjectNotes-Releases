# Security Reports / 安全问题反馈

Please do not disclose private notes, libraries, backups, credentials, or personal information in a public issue.

For a suspected vulnerability, use GitHub's private vulnerability reporting option in this repository's Security tab if it is available. If it is not available, open a minimal public issue requesting a private reporting channel without posting the exploit or sensitive data. Ordinary bugs can be reported with invented data through the issue template.

Include the app version, macOS version, a minimal reproduction using invented notes, and the potential impact. Do not attach a real library. There is no guaranteed response time or security certification for this preview.

Install only from this repository's Releases. Published SHA-256 checksums help detect changed downloads but do not authenticate a publisher or replace Developer ID signing. This release has no Apple notarization. Do not disable system-wide security protections.

安全问题请优先使用仓库 Security 页的私密报告入口。如果该入口不可用，只在公开 Issue 中请求建立私密渠道，不公开漏洞细节、私人笔记、资料库、密钥或其他个人信息。复现材料使用虚构数据。本预览版没有承诺响应时限或安全认证。
